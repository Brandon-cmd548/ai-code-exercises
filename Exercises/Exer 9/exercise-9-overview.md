# Exercise 9 Overview: Using AI to Improve Testing Practices

## Objective
The goal of this exercise was to develop stronger software testing skills by using AI as a guided learning tool rather than a direct solution provider. The focus was on understanding how to design, improve, and structure tests while building critical thinking and test-driven development (TDD) practices.

---

## Approach

A task prioritization system was used as the core application for testing. The exercise was divided into multiple stages, each targeting a different aspect of testing, from understanding function behavior to integrating full workflows.

AI was used interactively to guide thinking, ask questions, and highlight gaps in understanding, rather than generating ready-made solutions.

---

## Key Activities

### 1. Understanding What to Test
- Analyzed the behavior of the task scoring function
- Identified key functionality and expected outputs
- Explored edge cases and potential failure scenarios
- Developed a list of test cases based on guided questioning

---

### 2. Test Planning
- Created a structured testing plan for multiple related functions
- Identified different types of tests (unit and integration)
- Prioritized test cases based on importance and risk
- Defined expected outcomes and dependencies

---

### 3. Improving Test Quality
- Wrote an initial basic test for core functionality
- Refined the test with guidance to improve clarity and accuracy
- Strengthened assertions to ensure precise validation
- Identified missing edge cases and improved test coverage

---

### 4. Learning from Examples
- Explored better testing strategies for specific logic (e.g., date-based calculations)
- Evaluated what makes a test effective and maintainable
- Applied improvements to create more comprehensive and robust tests

---

### 5. Test-Driven Development (TDD)
- Practiced writing tests before implementing new features
- Implemented minimal code required to pass tests
- Iteratively expanded functionality through additional tests
- Applied TDD workflow to both new feature development and bug fixing

---

### 6. Integration Testing
- Designed tests covering the interaction between multiple functions
- Created test scenarios that reflect real-world usage
- Ensured correct behavior across the full workflow of the system

---

## Skills Demonstrated

- Test case design and planning
- Identification of edge cases and failure conditions
- Writing clear and maintainable tests
- Improving test accuracy and coverage
- Applying Test-Driven Development principles
- Understanding the relationship between unit and integration testing
- Using AI as a collaborative tool for learning and reasoning
- Critical evaluation of test quality and effectiveness

---

## Outcome

This exercise resulted in a structured and comprehensive approach to testing a software system. It demonstrates the ability to design effective tests, improve test quality through iteration, and apply best practices such as TDD and integration testing. It also highlights the capability to use AI tools responsibly to support learning, validation, and deeper understanding of testing concepts.
