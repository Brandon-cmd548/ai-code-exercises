# Codebase Understanding Exercise 3 – Overview

## Objective

This exercise focused on developing the ability to understand and navigate an unfamiliar codebase using a structured, methodical approach supported by AI prompting techniques.

The goal was not to immediately modify or extend the system, but to build a clear mental model of how the application is structured, how features are implemented and how data flows through the system before making changes.

---

## Key Focus Areas

### 1. Understanding Project Structure
- Analyse the directory structure and key files without deeply reading all code  
- Identify technologies, frameworks and main components  
- Form an initial hypothesis about how the system is organized  

---

### 2. Locating Feature Implementation
- Investigate how existing functionality is implemented  
- Practice searching for relevant code using keywords and patterns  
- Identify where new features (e.g., exporting tasks to CSV) would fit within the existing architecture  

---

### 3. Understanding the Domain Model
- Identify core entities such as tasks, statuses and priorities  
- Understand how these entities relate to each other  
- Interpret business logic and domain-specific rules in the application  

---

### 4. Applying Knowledge to a Real Scenario
- Plan how to implement a new business rule:
  > Automatically mark tasks as abandoned if overdue for more than 7 days, unless marked as high priority  
- Identify affected components and required changes  
- Think through implementation before writing code  

---

## Approach

The exercise emphasizes a structured workflow:

1. Form an independent understanding of the system  
2. Use AI prompts to validate and refine that understanding  
3. Identify gaps and misconceptions  
4. Iterate on explanations and mental models  

---

## Outcome

By completing this exercise, the objective is to demonstrate the ability to:

- Quickly understand unfamiliar codebases  
- Identify architecture and component responsibilities  
- Trace how features and data flow through a system  
- Plan feature implementation based on existing design  
- Use AI effectively as a tool for deeper reasoning, not as a shortcut  

---

## Summary

This exercise simulates a real-world scenario where a developer must join an existing project, understand how it works and confidently plan changes. The focus is on analysis, reasoning and structured problem-solving, rather than immediate code implementation.
