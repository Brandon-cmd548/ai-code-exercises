# Code Comprehension Exercise – Task Manager

## 🔹 Overview

This project is part of a **Code Comprehension Challenge**, where the goal is to understand an unfamiliar codebase **without modifying it**, using structured exploration and AI-assisted reasoning.

The application is a **task management CLI tool** built in JavaScript, allowing users to create, update, and track tasks.

---

## Objective

The goal of this exercise was to:

- Understand how the codebase is structured  
- Identify how core features work (task creation, prioritization, completion)  
- Trace data flow through the system  
- Use structured prompts to deepen understanding  
- Document findings clearly  

---

## Exploration Tasks

### 1. Understanding Key Features
- Identify files involved in task creation and updates  
- Trace execution flow step-by-step  
- Understand how tasks are stored and retrieved  
- Recognize architectural patterns  

---

### 2. Deepening Understanding
- Analyse how task prioritization works  
- Form an initial understanding before validation  
- Use guided questions to refine reasoning  
- Identify and correct misconceptions  

---

### 3. Mapping Data Flow
- Follow what happens when a task is marked as complete  
- Identify state changes and data movement  
- Understand how changes are persisted  

---

### 4. Reflection
- Summarise application architecture  
- Explain key features  
- Identify challenges and learning points
